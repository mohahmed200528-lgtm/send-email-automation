# Send Email Automation

An email automation project built with **n8n** as part of the Digital Egypt Pioneers Initiative (DEPI) – AI Automation Track.

## Project Overview

This project automates the email-sending process using n8n workflows, helping reduce manual tasks and improve communication efficiency.

## Workflow

The workflow is exported as a JSON file that can be imported into n8n.

**Main file:**
- `sendEmail.json`

## Technologies & Tools

- n8n
- Workflow Automation
- Email Integration
- JSON

## How to Use

1. Download `sendEmail.json`.
2. Open your n8n instance.
3. Create a new workflow.
4. Import the downloaded JSON file.
5. Configure your own email credentials.
6. Test and activate the workflow.

## Security

Credentials and API keys should be configured inside n8n. Never share private credentials in the repository.
